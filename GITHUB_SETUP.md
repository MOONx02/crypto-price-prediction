# GitHub repo setup

Do this once to put this project on GitHub.

## 1. Create the repo on GitHub

1. Go to [github.com/new](https://github.com/new).
2. Repository name: e.g. `crypto-price-prediction` or `ecps211-final-project`.
3. Choose **Private** (or Public if you prefer).
4. Do **not** add a README, .gitignore, or license (we already have them).
5. Click **Create repository**.

## 2. Initialize git and push (from this folder)

In a terminal, open the project folder and run:

```bash
cd "/Users/moon/Library/Mobile Documents/com~apple~CloudDocs/WINTER2025/211/crypto-price-prediction"

git init
git add .
git commit -m "Initial project: plan, README, requirements, structure"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git
git push -u origin main
```

Replace `YOUR_USERNAME` and `YOUR_REPO_NAME` with your GitHub username and the repo name you chose.

## 3. Add collaborators

Repo → **Settings** → **Collaborators** → **Add people**. Add your group members so they can push.

## 4. After that

- Commit and push regularly: `git add . && git commit -m "message" && git push`
- Pull before you start work: `git pull`
- Use one main branch; avoid editing the same notebook at the same time to prevent merge conflicts.
